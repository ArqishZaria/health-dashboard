Tips
  • Always start from the "Download Template" button above for your chosen form type - the headers must match exactly for a row to import correctly. The template's "Instructions" sheet has the full details.
  • Dates must be in YYYY-MM-DD format (e.g. 2026-03-05) - no other format is accepted. A row with a date in any other format, or an invalid calendar date, is rejected with an error rather than being guessed or defaulted.
  • Region, Local Council and Jamatkhana values are cross-checked against existing records only - bulk upload never creates new geography. If a row references geography that doesn't exist yet, it won't be accepted.
  • Unrecognised columns are preserved and stored against each record - nothing is silently dropped.
  • Maximum file size: 10 MB.
